### 1.「法律」专家—长期出题任务

| 字段 | 内容 |
|------|------|
| **时薪** | 200-300¥/小时 |
| **任务类型** | 专业出题 |
| **项目周期** | 长期（8-10月持续） |
| **难度** | ⭐⭐ 中低 |

**完整任务描述：**
本项目面向法律垂类领域，建设一批可用于大模型 Agent 能力评测的高难度任务。专家需基于下方法律业务场景分类，在真实法律实践语境下设计完整题目包（任务描述、子任务拆解、参考答案、评分表），并完成必要的自检，确保题目评分表设置合理且参考答案能在自己的评分表中得到高分。

**怎么做：**
- 交付物：题目包 = 任务描述 + 子任务拆解 + 参考答案 + 评分表
- AI 辅助点：用 AI 帮你生成初版题目框架、评分 rubric 模板，再基于真实法律经验修改
- 自检要求：参考答案必须在自己的评分表中拿高分
- 关键：题目要体现"真实法律业务链路"，不能是教科书式的知识问答

**评估：法律本行，流程标准化，长期稳定收入。AHT（单题耗时）约 3-6h，每题 1200-3000 元（按项目定价），折合时薪 200-500¥/h。AI 可大幅提效。**

### 2.「法律」专家—Hard Legal Agent 出题项目

| 字段 | 内容 |
|------|------|
| **时薪** | 300-500¥/小时 |
| **任务类型** | 高难度出题 |
| **项目周期** | 未明确，持续招募中 |
| **难度** | ⭐⭐⭐ 中 |

**完整任务描述：**
随着法律 Agent 在法规检索、合同审查、案件分析、合规风控与法律文书处理等场景中的应用不断深化，现有题库在真实法律业务链路、多类型文件协作及高难度任务覆盖方面仍有不足。本项目现招募法律专家参与 Hard Legal Agent 高难度法律出题任务。专家需基于真实法律工作场景及多类型文件，完成材料脱敏、题目设计和说明文档撰写，建设覆盖复杂法律业务流程的端到端任务，持续探测模型在法律推理、文件处理、多步决策等方面的能力上限。

**覆盖场景：**
- 法规检索
- 合同审查
- 案件分析
- 合规风控
- 法律文书处理

**怎么做：**
- 交付物：脱敏材料 + 题目设计 + 说明文档
- 比任务 1 多了"材料脱敏"和"多类型文件协作"的要求
- 题目需覆盖"端到端"复杂业务流程，不是单点问题
- AI 辅助点：帮脱敏（替换当事人信息）、生成多步骤任务框架

**评估：比#1 难度高一档，但时薪也更高。核心挑战是设计"多步骤、多文件"的复杂场景题，需要真实办案经验。适合有实务经验的法律人。**

### 3.「专业咨询」专家—AI 语音对话录制

| 字段 | 内容 |
|------|------|
| **陪聊时薪** | 100-125¥/小时 |
| **主发报酬** | 约 5000 元/成品小时 |
| **任务类型** | 双人语音录制 |
| **难度** | ⭐⭐ 中低 |

**完整任务描述：**
本项目邀请具备真实行业经验和专业咨询能力的专业人士，围绕实际工作及生活问题进行自然语音咨询录制。对话场景包括：**法律咨询、财税咨询、教育咨询、健康咨询、职业咨询、生活咨询**。专家可根据自身专业背景及擅长领域选择对应方向参与，交流需兼顾专业性、可信度和自然互动感。

**项目流程：** 进试音群 → 试音（约5–10分钟，试音环节不结算费用）→ 正式作业

**费用说明：**
- 主发音人：约 5000 元/成品小时，按最终有效成品音频时长结算（去掉静音段、口水音、重录部分等）
- 陪聊角色：100-125 元/小时，按实际参与时长结算

**参与方式：** 无需审核报名，可直接通过链接进入试音群

**怎么做：**
- 选择"法律咨询"方向，模拟真实法律咨询场景对话
- 需要两人配合（主发+陪聊），可以找搭档或等平台分配
- 主发角色报酬极高（5000¥/成品小时），但需要专业表达+自然互动
- 试音 5-10 分钟，通过后正式作业

**评估：法律咨询方向完美匹配。主发角色收入天花板最高（5000¥/h），但需要口语表达能力强。陪聊角色门槛低但收入也低。建议先试音争取主发。**
