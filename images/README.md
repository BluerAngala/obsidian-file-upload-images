# 律师四件套工具库（MVP）

一条生产线：获客（通讯录+内容）→ 接案（流程地图+材料AI）→ 交付（模板库）→ 复购（通讯录闭环）

## 目录

| 目录 | 工具 | 当前状态 |
|---|---|---|
| `01-模板库/` | 文书模板（9 类纠纷 × 文书类型，{{变量}} 占位） | 骨架 + 2 个示例 |
| `02-流程地图/` | 案件全流程 SOP（阶段 × 节点 × 文书 × 坑） | 个债起诉完整样例 |
| `03-材料AI/` | 材料整理 Prompt 体系（证据目录/缺失清单/风险点） | Prompt + 示例输出 |
| `04-通讯录/` | 案源联系人表（信任复利 CRM 字段） | 表结构 + 示例 |

## 使用方式

- 模板：复制到案件文件夹 → 替换 {{变量}} → 交给 AI 润色/填充
- 流程地图：办案时对照节点 checklist，结案后更新"坑"与"文书"
- 材料AI：把当事人材料描述丢进 Prompt → 得到证据目录初稿 + 缺失清单
- 通讯录：每案必录，结案必跟进

## 落地顺序（3 周）

- 周 1：目录体系 + 模板库补全（每类 1 个高频模板）+ 通讯录建表
- 周 2：个债流程地图完整版 + 材料AI 实测 1 个真实案例
- 周 3：其余 8 类流程地图套结构填充 + 模板库扩充
- 周 4 起：边办案边沉淀，每案归集模板/流程更新/通讯录跟进

## 沉淀规则（每案必做）

1. 新文书 → 归入模板库（去客户信息，留变量）
2. 新坑/新节点 → 更新流程地图
3. 材料新情况 → 更新材料AI 的提示词
4. 联系人 → 更新通讯录并记录下次跟进
